国内域名与 IP 库来自 [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat) 的 `sing` 分支，首次安装附带快照，运行后由 sing-box 每天经 `proxy` 检查更新并缓存。

- 域名：`https://raw.githubusercontent.com/MetaCubeX/meta-rules-dat/sing/geo/geosite/cn.srs`
- IP：`https://raw.githubusercontent.com/MetaCubeX/meta-rules-dat/sing/geo/geoip/cn.srs`

域名和 IP 归属按该规则库判断，并不保证对所有网站都准确；个人覆盖规则放在 `routing.json` 的规则列表最前面。
